## Setup

The font used by this game is not included in this repository.

### Font

This game uses **DotGothic16**.
Get the font from [Google Fonts](https://fonts.google.com/specimen/DotGothic16) and place the Bold font file at `third_party/fonts/DotGothic16-Regular.ttf`.
